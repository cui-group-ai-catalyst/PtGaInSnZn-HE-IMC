# Readable white-background 3-D package

This package is a display-only upgrade of the approved white-background 3-D view.
The point coordinates, brightness values, layer indices, default camera and layer
spacing are unchanged. Edit `render_white_layered_3d_readable_v2.py` and the
`STYLE` dictionary to regenerate static outputs. Open the interactive HTML to
adjust axis title/tick size, axis/grid colours, opacity, point size, layer spacing,
projection, guide rings and colour-bar placement. The HTML export uses the current
plot dimensions at 2x resolution, so adjusted sizes are preserved. SVG/PDF text
remains editable.
